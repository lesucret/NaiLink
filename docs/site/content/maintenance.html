切换 dae / sing-box / mihomo

sing-box 自 0.6.34、mihomo 自 0.6.40 起可用。点击面板顶部“内核”，选择目标 后按“下载并安装 → 检查兼容性 → 切换”操作。默认仍是 dae，升级不会自动切换；现有节点、订阅和待生效编辑保留。切换会短暂断连，失败尝试自动回退，关闭窗口不取消后台任务。

sing-box / mihomo 支持已能安装 NaiLink 的 x86_64 / ARM64 固件，需要 TUN、nftables / fw4 与额外 180 MiB 可用存储，建议内存 1 GiB 以上。暂不开放 32 位可选内核，也不保证所有协议、复杂 DNS 或自定义策略都能转换。请先阅读兼容性报告。支持范围、差异与恢复说明。

打开安装管理菜单

0.6.35 使用 1.14.3-nailink.1 可选兼容构建，修复真机复现的 Reality 握手问题，并提供完整对应源码。 如果此前安装了官方 1.14.3，请先保持 dae，在“内核”窗口检查兼容性，按提示重新安装可选内核后再检查和切换。 报告会一次列出当前运行节点的中文问题，原链接和配置保留。

安装成功后，在路由器 SSH 中运行：

nailink
选项 作用
1 安装 / 更新 联网获取发布脚本，已有安装先备份并保留数据升级。
2 卸载 确认后先备份，再删除插件和当前数据；可离线执行。
3 检查环境 检查兼容性，不修改系统。
0 退出 不执行安装或服务操作。

保留数据更新

0.6.32 起可直接在面板更新：点击顶部版本号，等待检查发布版本，再点击“更新到…”；完成后选择“重新加载新版本”。任务在路由器后台执行，关闭弹窗或切换菜单不会取消。安装前仍会检查兼容性并备份，连接可能短暂中断，请勿断电。

旧版本请先用 SSH 菜单或下面的固定版本命令升级一次，之后才会显示版本按钮。更新需要路由器能访问 GitHub；下载、校验或环境检查失败时，原服务和数据不会被替换。断电或服务故障后可重新打开版本窗口查看结果；失败原因不明确时，先检查运行日志，避免重复执行。

SSH 菜单仍然可用：

0.6.33 起，在线更新在停服前额外下载并校验当前版本的回退安装包；无法取得回退包时，原服务继续运行。备份失败会恢复旧服务，安装失败或管理 HTTP 未就绪会尝试恢复旧包和配置快照。升级期间请等待维护任务结束再编辑配置。

原始备份和失败现场备份均位于 /root/daed-backups。磁盘损坏、原生包管理器异常或回退也失败时，页面会明确提示，不能保证自动恢复；请保留备份，通过 SSH 修复，避免卸载清除数据。符号链接到外部存储的数据库或配置不走自动在线回退，应先备份外部数据后手动升级。

  1. 先到发布页查看版本说明及兼容性。
  2. 运行 nailink，选择 1 安装 / 更新。
  3. 等待下载、校验、环境检查、备份和安装完成。更新期间服务可能短暂停止。
  4. 重新登录或刷新 LuCI，进入“服务 → NaiLink”；仍显示旧页面时按 Ctrl+F5。
  5. 检查节点、订阅、群组及原配置，并按需应用配置后验证联网。

更新保留节点、订阅、群组、规则与自启选择，不需要先卸载。若想固定到本教程对应版本，可直接执行：

nailink --install --release $release

旧版菜单遇到 raw.githubusercontent.com 解析失败时，这个固定版本入口也可绕过旧 Raw 下载入口。若 github.com 也不能访问，先修复路由器自身 DNS 或网络，参见下载失败。

更新后如何判断代理已恢复

0.6.30 起，更新脚本分别检查管理页面、代理监听、DNS 上游初始化和缓存路由恢复。网络仍在恢复时会提示状态并保持服务运行，保留节点和配置。SSH 执行下面的只读检查可查看详情： 

nailink --check-network

诊断会显示群组策略和 IPv4 / IPv6 候选节点，并对 Google、ChatGPT 发出有时间限制的请求。候选节点不是网站实际看到的公网出口 IP；自动选择可能在重启后选中不同节点。网站的 VPN 提示还可能取决于出口信誉、账户和会话，不能通过代理就绪状态判断。

正常停止时，最多 1024 条、2 MiB 的仍有效 DNS 地址记录保存在 /var/run/daed，仅在配置匹配、快照不超过 10 分钟且原 TTL 未过期时恢复，按当前规则重建分流关联。不会延长 DNS TTL 或改动配置。该目录为易失存储，重启路由器后会消失。

首次从 0.6.29 或更早版本升级没有旧快照可用。新版本之后的正常服务停止、重启和升级才会使用该机制；不能保证断电、强制杀进程后恢复。升级会关闭原进程的连接，新请求仍需要重新建立连接。

备份在哪里，包含什么

备份保存在 /root/daed-backups。安装器会先停止服务并等待退出，再归档配置、数据库及 WAL，以避免复制正在写入的数据。 

ls -lh /root/daed-backups

请把需要长期保留的归档另存到可信设备。备份可能包含节点密码、订阅令牌和账户信息，不要公开上传。目录权限为 0700，归档权限为 0600。

更新失败不会自动回滚

下载或兼容性检查失败时不会替换现有程序；进入安装后若失败，可能已经停止服务。先保留报错和备份路径，确认软件包状态，再决定恢复。不要重复运行清空重装来排查。

需要恢复备份时怎么办？

目前菜单没有“一键恢复备份”选项。先停止 NaiLink，保留当前目录的另一份副本，核对归档内的路径、原版本和数据库状态，再由熟悉该固件的人恢复。不要直接向运行中的数据库覆盖文件，也不要把另一台路由器的接口配置整体覆盖进来。

卸载：先备份，再清理

  1. 运行 nailink，选择 2 卸载。
  2. 阅读提示，输入 y 确认。
  3. 卸载会先停止服务并创建备份，再清理插件及当前节点、订阅、群组与配置。
  4. 保留的备份仍在 /root/daed-backups；共享依赖和已有 BTF 不会因此一并删除。

卸载可以离线执行。旧版或需要直接使用命令时：

daed-router-setup --uninstall

上面这条直接命令不经过菜单确认，执行前请确认确实要删除插件与当前数据。正常更新不要使用它。

什么时候才用清空重装

--reinstall 用于明确需要清空旧配置或替换其他来源的 Daed 包的情况，会先备份再清理，但不会自动导入备份。原节点和规则需要重新配置，不能把它当普通升级方式。

新旧品牌沿用 daed 服务、daed-router / luci-app-daed-router 包名和 /etc/daed 目录，所以系统里看到旧名称属于预期，不代表品牌更新失败。

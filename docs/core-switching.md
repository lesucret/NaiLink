# dae / sing-box 内核切换

从 NaiLink 0.6.34 起，可在面板顶部点击“内核”。默认仍是 dae，升级不会自动换内核。

1. 选择 sing-box，点击“下载并安装”。下载或校验失败不停止当前代理，可重试。
2. 点击“检查兼容性”，查看不兼容原因和行为差异。修改配置后需重新检查；未应用的编辑不会被切换顺带应用。
3. 检查通过后切换。切换会短暂断连，请等待结果，不要断电。关闭窗口不会取消后台任务。
4. 想切回时选择 dae，重新检查，再切换。

0.6.36 修复手动/订阅节点测试时对 SS `type=tcp`、HY2 `security=tls`、Reality 混合密钥协商提示和 VMess 导出元数据的兼容。VMess 的 `verify_cert` 会转换为对应证书校验设置；与其他选项矛盾时拒绝，不自动放宽验证。HY2 的有效 Base64 ECH 配置会保留到原生 TLS；公开域名为空或格式异常时明确提示，不静默删除 ECH。

节点结果中的“参数不兼容 / ECH 配置异常”发生在测试发起前；“超时”表示连接未在期限内完成。订阅内的流量、到期日期、官网等提示项应与真实可连接节点区分，不能据此判断整个协议不可用。兼容性检查只覆盖当前运行配置；订阅列表里的其他节点会在各自测试时检查。

0.6.35 补齐 `headerType=none`、VLESS/Trojan 的 `udp` 开关与 Reality `spx` 参数处理。检查会列出当前运行配置中每个不兼容节点的名称和中文原因，附加参数仅显示名称，不输出密码或完整链接。`spx` 对应 Xray 验证失败后的爬虫路径，sing-box 不执行此行为；原链接保留，报告会说明差异。配置检查不代表机场线路一定可用，实际切换仍需通过 DNS 和连接检查。

本版同时支持当前规则引用的外部 GeoIP/GeoSite `.dat` 文件，不删除 AdZero 等插件加入的规则；外部规则变化后需要重新检查。较大的规则库使用有界的独立原生配置检查时间，超时与配置错误分别提示。

按域名拨号模式会在代理规则匹配后使用嗅探到的有效域名，减少旧 DNS 地址造成的连接失败；直连规则和按 IP 拨号保持原行为。尚不能等价转换的高级拨号模式会明确阻止切换，不自动改为其他模式。

## 首版范围

| 项目     | 范围                                                                                       |
| -------- | ------------------------------------------------------------------------------------------ |
| 架构     | sing-box：x86_64、ARM64；ARMv7/MIPS 保持原 dae 支持限制                                    |
| 安装前提 | 已能安装 NaiLink；原安装器仍检查 dae 的 eBPF/BTF 条件，不是绕过旧内核限制的新安装途径      |
| 接管方式 | dae 使用 eBPF；sing-box 使用 Linux TUN、nftables，提供 fw4 include                         |
| 资源     | 安装可选内核需要额外 180 MiB 可用存储，建议路由器有 1 GiB 以上内存                         |
| 常见节点 | SS/SS2022、VMess AEAD、VLESS、Trojan、HY2、AnyTLS、TUIC v5、SOCKS、HTTP/HTTPS 的已适配参数 |
| 规则库   | 读取现有 GeoIP/GeoSite `.dat` 中引用的条目，生成 sing-box 原生规则，不覆盖原文件           |

尚未适配的 SSR、Juicity、Naive、ShadowTLS、链式代理及部分高级参数会阻止 sing-box 切换；不承诺兼容所有协议。多 WAN、固定群组包含多个节点、自定义策略参数、MAC 分流和部分高级 DNS 规则也暂不转换。兼容性报告以实际运行配置为准，节点和原始配置一直保留。

自动选择映射为 sing-box URL 测试策略，平滑算法与 dae 不完全相同；节点域名引导解析使用首个直连 DNS 上游，其余上游经默认群组。切换会清空原内核的运行缓存，可能改变自动选择的出口，已有浏览器连接不能无缝迁移。AI 服务是否接受出口还取决于节点 IP 和网站策略。

## 失败后怎么办

目标内核配置不通过时不切换。启动或连接检查失败时，先撤销目标资源，再尝试恢复原内核和运行配置；节点、订阅、群组及待生效编辑不会删除。刷新后重新打开“内核”可查看结果，运行日志和 `nailink --check-network` 也会显示当前内核。

回退也失败、磁盘异常或无法确认资源归属时，面板会明确提示。不要反复切换或卸载；先保留 `/root/daed-backups` 与现有配置，再检查日志。内核意外退出仅有限次自动重启，避免持续重启占用资源。

可选程序固定为 **1.14.3-nailink.1 兼容构建**，基于 [sing-box 1.14.3 源码](https://github.com/SagerNet/sing-box/tree/v1.14.3)，修复本次真机复现的 Reality 密钥份额处理问题。保留指纹、SNI、公钥、短 ID 与认证校验，未放宽安全验证。[构建方法和补丁范围](../openwrt/singbox.md)可审查，静态程序及对应源码随 NaiLink 发布，下载仍核对固定 SHA256、架构与版本。

已装过官方 1.14.3 的用户，升级 NaiLink 后先保持 dae，在“内核”窗口检查兼容性，按提示重新安装可选内核，再检查和切换。此操作不删除节点、订阅或原配置。发布包不自动启动第二套代理服务。mihomo 属于[后续规划](multi-core-plan.md)，本版没有接入。
